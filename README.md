# 安真魔法學院

給小朋友的學習入口網站：<https://laierin615.github.io/anzhen-magic-academy/>

- **音樂教室**：連到「浪漫樂派大冒險」互動電子書（[romantic-music-ebook](https://github.com/laierin615/romantic-music-ebook)）。
- **語文教室**：字音字形咒語特訓。毛毛老師陪你練全國語文競賽國小學生組 102–114 年決賽題目，可以翻牌對答案，答錯的題目會自動收進錯題本。「練習類型」裡的「🏆 模擬賽」比照正式比賽：字音、字形各 100 題（另有半卷、迷你卷），可選歷屆原卷或隨機組卷。計時分「正式節奏」每字 3 秒（200 字 10 分鐘）和「線上節奏」每字 9 秒；作答中不對答案，交卷後自動批改，每字 0.5 分。
  - 自動批改：字形題在手寫格寫國字，送 Google 輸入工具手寫辨識（只送筆畫座標），前三名候選有目標字就算對；字音題用畫面上的注音鍵盤，與答案逐字比對。批改錯了可以手動改判。
  - 紙上寫：在紙上作答、翻牌自己對答案。

## 題庫

- 來源：教育部全國語文競賽國小學生組國語字音字形決賽試題與公布答案（102–114 年），由試卷影像逐題轉錄。113 年取自學校轉載的解答卷，114 年取自全國語文競賽官網公布的答案卷更正版。
- 共 2,582 題。102 年有 13 題字音、113 年有 1 題字音，因為解答卷使用的注音字型疑似印出預設讀音而存疑，另外還有 4 題無法辨識，這些都先不收錄。
- 卷面讀音和萌典（教育部重編國語辭典）不同的題目，翻牌時會另外提醒。
- 資料檔：`language/data/bank.json`。欄位說明：`y` 年度、`t` 音／形、`n` 題號、`w` 語詞、`i` 目標字位置、`z` 注音、`a` 辭典另讀。

純靜態網站，練習紀錄只存在使用者自己的瀏覽器（localStorage）。
